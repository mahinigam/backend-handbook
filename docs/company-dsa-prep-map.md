# Company-topic preparation matrix

This matrix is a **study-planning heuristic**, not a verified ranking of interview questions asked by each company. Validate current processes with official recruiting information and recent, well-sourced candidate reports; company interview formats change.

| Company | Core topics to prepare | Stretch focus | Reference notes |
|---|---|---|---|
| Microsoft | Arrays, strings, hash maps, linked lists, trees, graphs | Dynamic programming, object-oriented design, communication | Practice explaining trade-offs and testing edge cases. |
| Amazon | Arrays, strings, trees, graphs, heaps, intervals | Greedy, dynamic programming, complexity analysis | Pair coding preparation with leadership-principle examples where relevant. |
| Google | Arrays, strings, trees, graphs, binary search, dynamic programming | Graph algorithms, advanced optimization, proof of correctness | Expect to clarify constraints and justify complexity; exact formats vary. |
| Meta | Arrays, strings, hash maps, trees, graphs, intervals | Graph traversal, dynamic programming, problem decomposition | Timed practice may help; confirm role-specific expectations. |
| Atlassian | Arrays, strings, trees, graphs, design fundamentals | Practical problem solving, API and object-oriented design | Prepare for the specific team and level. |
| Adobe | Arrays, strings, linked lists, trees, stacks, dynamic programming | Graphs, recursion, system fundamentals | Use role-specific reports cautiously. |
| Uber | Arrays, hash maps, graphs, heaps, intervals | Graph traversal, optimization, practical systems reasoning | Include edge cases and real-world constraints in explanations. |
| Accenture | Arrays, strings, sorting, searching, hash maps | Basic trees, recursion, complexity fundamentals | The process varies by country, role, and hiring program. |
| Target | Arrays, strings, hash maps, trees, graphs | Practical coding, data modeling, role-relevant design | Do not assume every role uses the same interview loop. |
| ZS Associates | Arrays, strings, sorting, searching, hash maps | Quantitative reasoning, optimization, SQL/data handling when role-relevant | Separate software engineering preparation from analytics-oriented assessments. |

## Common preparation order

1. Arrays and strings
2. Hash maps and sets
3. Two pointers and sliding window
4. Stacks, queues, and binary search
5. Linked lists and trees
6. Heaps, intervals, and greedy methods
7. Graph traversal and shortest paths
8. Backtracking and dynamic programming
9. Mixed timed practice and review of failed attempts
